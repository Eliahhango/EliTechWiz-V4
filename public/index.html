Connect WhatsApp How it works

Connection dashboard

WhatsApp is not connected.

Use the number already registered on WhatsApp, without spaces or plus signs.

Enter this code in WhatsApp

  1. Keep this page open. Do not refresh until WhatsApp shows Connected.
  2. On your phone, open WhatsApp > Settings > Linked devices.
  3. Tap Link a device, then Link with phone number instead.
  4. Enter the 8-digit code. WhatsApp should then show a confirmation to link this device. Approve it.

The live QR code will appear here.

  1. Open WhatsApp on your phone.
  2. Go to Settings > Linked devices > Link a device.
  3. Scan this QR code. It refreshes automatically when WhatsApp issues a new one.

Pairing code

Best on the same phone. Request a genuine WhatsApp pairing code and type it into Linked devices.

QR code

Best from a computer. Scan the live code from WhatsApp. Expired codes are replaced automatically.
